# MES 工厂首轮执行与回传清单

本清单用于验证当前 `MES_TASK_UNION`（含六类任务）、客户六分支基线、性能，以及导入后 PACKAGE 未覆盖清单。
本机不能连接 MES，因此“工厂通过”只能在完成回传导入后确认。

**不再要求客户批准文件。** 可选写入实验记录（谁/何时/备注）。  
**来回用文件夹拷贝即可**，不必压缩、不必校验 SHA-256。  
密码与已填写的 `mes-config.ini` 只留在工厂机本地，**拷出/拷回前删除**，永不进仓库。

## 三、工厂执行

以下命令均在 bundle 根目录执行（`--bundle .`）。  
`--output-root .\mes-runs`：三个 `run-...` 都写在本目录下的 `mes-runs\`。  
`--experiment-record` 可省略；省略时 manifest 记 `not-provided`。  
工厂命令用**单行**粘贴（PowerShell 5 反引号续行易乱序）。  
`mes-config.ini` / `experiment-record.json` 若含中文，请用 **UTF-8 无 BOM** 保存。
