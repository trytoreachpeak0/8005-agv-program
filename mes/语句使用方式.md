1. 定时查询 MES 装片完工待搬运数据

2. 根据 product_lot + machine_no + finish_time / MES事务ID 去重

3. 如果本地没有任务：
      创建 New 任务

4. 如果本地已有任务：
      不重复创建
      根据本地状态处理

5. 如果任务状态是 New：
      AGV 空闲时可以派车

6. 如果任务状态是 Missing / Exception / Done / Cancelled：
      即使 MES 还查到，也不自动派车

7. AGV 到机台后：
      必须扫码 / 传感器 / 人工确认物料

8. 如果物料存在：
      执行搬运
      到达后调用 MES 或提示 OP/PDA 操作

9. 如果物料不存在：
      标记 Missing
      告警给 OP / 班组长 / 中控
