# 确定版本化基线模式

Type: grilling
Status: resolved
Blocked by: 03, 04, 05, 06

## Question

当前需求应被永久冻结，还是应冻结每个已批准版本并允许以后通过受控变更发布新版本？

## Answer

这是 2026-08-03 由用户在本次 Codex 对话中重新作出的基线治理决定，不是恢复出的历史事实。用户明确回复“可以”。

- 本次确认后形成首个完整、无已知未决真实冲突的当前需求基线版本。
- 每个已批准版本绑定 Git commit、文件哈希和批准记录，并保持可恢复。
- 后续新增、修改或废弃需求先作为待批准变更，不立即改变已批准基线。
- 变更完成来源确认、影响分析、冲突处理和人工批准后，发布新的基线版本。
- “当前基线”指向最新批准版本；旧版本继续保留。
- 每个新版本记录相对上一版本新增、修改和废弃的需求以及批准证据。

Evidence: 本次 Codex 对话记录，2026-08-03，用户对“建立首个版本化当前需求基线及其后续变更规则”答复“可以”。
