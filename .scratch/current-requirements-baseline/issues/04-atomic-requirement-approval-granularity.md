# 确定需求确认的条目粒度

Type: grilling
Status: resolved
Blocked by: 01, 03

## Question

人工确认应作用于整份文档，还是作用于可独立判断的需求条目？

## Answer

这是 2026-08-03 由用户在本次 Codex 对话中重新作出的治理决定，不是恢复出的历史事实。用户明确回复“可以”。

- 文档是证据载体，不自动成为不可拆分的权威单元。
- 每项可独立判断的需求分别记录原文定位、版本、适用范围、来源链和确认状态。
- 同一文档可以同时包含已确认、派生、已废弃、AI 未确认和来源未知内容。
- 只有证据明确表示具名批准人批准了具体版本全文，且适用范围清楚时，才允许整份文档批量确认。
- 最终基线通过原文摘录和精确证据引用固定需求，不修改原始文档，也不由 AI 改写其含义。
