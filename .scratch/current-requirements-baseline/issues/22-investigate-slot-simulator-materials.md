# 调查仓位模拟器需求与决定

Type: research
Status: resolved
Blocked by: 11, 26

## Question

对无损清单 R10 批次中的模拟器愿景、需求、决定、设计、测试计划和参考资料，逐份核实来源、历史、批准证据、适用范围及其与多仓位 AGV 主系统需求基线的关系；哪些是主系统约束证据，哪些只属于开发辅助工具或设计实现？

## Answer

已完成 [R10 仓位模拟器材料调查](../evidence/investigations/R10-slot-simulator-materials.md)：固定清单中的 46/46 份材料均已按路径和 SHA-256 核验，并应用 2 条中文路径 Git 状态勘误。材料主体是尚未实现的开发辅助工具规划，包括 15 份模拟器 FR、15 份模拟器 DR、5 份设计/测试/实施材料、模板和索引；全部缺少当前基线要求的完整批准四要素，0/46 可直接视为已确认的主系统需求。厂商 PDF 仅能证明特定 C2000 型号的接口、寄存器和功能码，尚无项目采购、固件或布线证据把它绑定到 8005。报告另识别出锁 DI 镜像残留、OpenAPI 故障枚举落后及 Unit ID/地址换算未定等内部漂移，必须先回到主系统、现场或厂商来源核实，不能从模拟器设计反推需求。

后续范围决定：用户于 2026-08-03 明确供应商手册可以忽略。因此该 PDF 及其派生摘录只保留清单、哈希和来源审计记录，不再作为本次当前基线候选或外部约束来源；上述手册技术核验不触发后续适用性调查。
