# 确定需求证据盘点边界

Type: grilling
Status: resolved
Blocked by: 01

## Question

“全部需求文档”的盘点范围是否包括当前仓库、Git 历史、非 Markdown 资料、代码现状证据及外部引用？

## Answer

这是 2026-08-03 由用户在本次 Codex 对话中重新作出的范围决定，不是恢复出的历史事实。用户明确回复“可以”。

- 盘点当前仓库和全部可访问 Git 历史中的需求性文档，包括必要的已删除、重命名和不同分支版本。
- 当前候选范围包括但不限于 `requirement-documents/`、`project_agreements/`、`docs/adr/`、`.scratch/`、`CONTEXT.md`、`glossary/`，以及其他目录中实际表达需求、约束、验收标准或业务决定的材料。
- PDF、Office、图片、会议纪要、邮件导出等非 Markdown 资料同样纳入候选集合；权威性仍只按已确认的证据规则判断。
- 代码、测试、配置、日志和数据库结构只登记为现状或历史实现证据，不作为正确需求。
- 构建产物、依赖包和缓存默认排除；若其中存在无法在源文件找到的需求性材料，则登记并标明来源状态。
- 外部系统只在仓库存在明确引用，或用户之后提供访问入口时按需追溯。

Evidence: 本次 Codex 对话记录，2026-08-03，用户对上述盘点边界答复“可以”。
