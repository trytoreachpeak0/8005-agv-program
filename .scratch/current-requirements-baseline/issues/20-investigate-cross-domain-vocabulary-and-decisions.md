# 调查跨域词汇与架构决定

Type: research
Status: resolved
Blocked by: 11

## Question

对无损清单 R08 批次中的 CONTEXT、术语表与跨域 ADR，逐份核实决定来源、提出/接受主体、版本绑定证据、批准范围和当前适用性；如何区分业务需求决定、设计决定与仅用于沟通的词汇，并避免把 accepted 外观自动视为批准？

## Answer

完整调查见 [R08 跨域词汇与架构决定调查](../evidence/investigations/R08-cross-domain-vocabulary-and-decisions.md)。固定清单中的 57/57 份材料均已核实且 SHA-256 零漂移，0/57 具备完整批准四要素。当前 `CONTEXT.md` 与 ADR 0003～0055 的版本有同一提交中的 Cursor 共同署名，合计 54 份应归为“AI 生成或修改但尚未确认”；ADR 0001～0002 与旧术语表只能恢复编辑历史，不能恢复决定来源与批准链，归为来源未知。

55 个 ADR 中有 16 个业务/项目约束候选、2 个领域定义或物理事实主导决定、37 个纯设计决定；ADR 0038 与 0045 有明确替代证据，只保留为历史。调查还把三项不确定性收敛成可独立处理的问题：ADR 0018 与 0055 对操作员上下文清除时点不一致，ADR 0046 残留已被 0054 删除的“待整批确认”阶段，且 `CONTEXT.md` 与旧术语表缺少明确的入口/替代关系。这些问题另建 HITL 票；本票不自行选择新旧、不修改领域模型，也不把 ADR `accepted` 或 Git 作者视为业务批准。
