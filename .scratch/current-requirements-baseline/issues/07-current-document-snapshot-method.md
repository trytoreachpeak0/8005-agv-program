# 确定当前文档集合的快照方式

Type: grilling
Status: resolved
Blocked by: 02, 06

## Question

用什么可核查方式固定“当前文档集合”，以免后续文件变化静默改变盘点对象？

## Answer

这是 2026-08-03 由用户在本次 Codex 对话中重新作出的证据治理决定，不是恢复出的历史事实。用户明确回复“可以”。

- 以盘点开始时当前工作目录的实际文件集合为准，不只限于 Git 已跟踪文件。
- 同时记录当前分支、Git HEAD、工作区状态以及每份候选文档的内容哈希。
- 已忽略或未纳入 Git 的需求性文件仍进入清单，并明确标记版本控制状态。
- 盘点期间发生的文件变化作为新快照登记，不静默覆盖初始证据。
- 未提交代码修改只登记为工作区状态，不纳入正确需求判断。
