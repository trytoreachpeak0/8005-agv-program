# 定义流畅刷新、游标分页与取消模型

Type: grilling
Status: resolved
Blocked by: 01, 13

## Question

怎样精确定义按页手动/可选自动刷新、VISIBLE/GONE 独立游标历史、当前页重取、筛选提交、取消、超时、游标失效、页面切换和过期响应处理，才能满足已确认的流畅性指标且不显示错乱或陈旧状态？

## Answer

MesIngestWatch V2 采用按 Host 会话、按视图隔离的浏览状态机。概览、VISIBLE、GONE、IngestAlert 各自持有已提交查询、单页成功窗口、cursor 路径、当前页、稳定 ID 选择、最后成功时间与自动刷新偏好；跨页面导航不会混用状态。在同一次 Watch 运行中返回视图会立即恢复缓存，自动刷新开启时同时重取，首次进入无缓存视图则立即加载。重启后查询、页码、cursor、列表与选择复位，只持久化自动刷新、请求超时等明确的本机偏好。

列表统一采用固定 100 行的“单页窗口 + 上一页/下一页”，不再累积“加载更多”，不显示未知总页数或任意跳页。下一页使用当前响应的 `nextCursor`，上一页由客户端保存到达各页所用的 cursor 后重新请求；每次成功重取都会丢弃当前页之后的旧前进路径。VISIBLE、GONE、IngestAlert 的查询与 cursor 历史彼此独立。默认查询分别为：VISIBLE 无时间窗、`DATES desc`；GONE 为最近 24 小时、`GoneAt desc`；IngestAlert 仅活动告警，按服务端 ERROR→WARNING、同级最后出现时间倒序的优先级。

筛选编辑属于草稿，不改变当前结果；点击“查询”并通过本地校验后请求第一页，只有成功才原子提交查询、窗口和新 cursor 路径，失败则保留原结果与待修正草稿。“重置”恢复默认并立即查询；点击可排序表头本身是一次显式查询并重开第一页。翻页同样只在成功后提交新页，失败仍停留原页。刷新成功后按 `DemandId`/`AlertId` 保持选择并更新详情；所选项消失时清空选择和详情并提示，不自动跨状态追踪；翻页或新查询成功后默认无选择。

所有请求严格单飞且用户操作优先：自动刷新到点但已有请求时跳过、不排队；手动刷新、翻页、提交查询或切换页面会取消旧请求并立即开始新请求。每个请求受 Host 会话、视图和请求代次共同约束；取消、被取代或属于旧 Host 的响应即使最终返回，也不得更新列表、详情、状态栏或错误横幅。请求期间提供专用“取消”；用户取消只显示中性状态、不记连接故障，导航引发的自动取消不提示。

当前页刷新时保留最后成功窗口并显示刷新中，成功后一次性替换；超时或失败保留旧数据，显示失败、最后成功时间和陈旧程度。概览的多资源读取共享取消与代次，但按资源原子提交：成功卡片可更新，失败卡片保留自身最后成功值与时间，整页标明部分失败且不伪装为同一时刻快照。全部成功才标记概览整体最新；用户取消前已成功提交的资源可以保留。

列表 cursor 类 `400` 会清空该查询页路径并只自动重试一次第一页；成功后明确提示已返回第 1 页，仍失败则保留旧窗口且不循环重试。其它筛选、时间范围、排序或 limit `400` 不自动恢复。`410 SYNC_CURSOR_EXPIRED` 只属于 DemandChangeFeed，不用于 Watch 列表。

自动刷新默认关闭，概览、VISIBLE、GONE、IngestAlert 分别持久化；启用默认 10 秒，可选 10/30/60/300 秒，且只有当前可见视图运行。切回启用自动刷新的视图立即刷新一次；每次成功、失败、超时或主动取消后从终止时刻重新计时，手动刷新也重置计时。失败不即时重试、不做指数退避。请求超时为全局设置，默认 30 秒、合法范围 1–300 秒；变更只影响后续请求。超时是连接失败，须保留旧数据并显示 endpoint、等待时长、最后成功时间和 correlation id，沿用连接事件日志规则。

应用新的 Host 地址或凭据会建立全新 Host 会话：立即取消并永久作废旧请求，清空所有业务缓存、选择、cursor、成功时间和旧 Host 错误，只保留纯本机偏好，然后回到概览执行首次加载。新 Host 连接失败或契约不兼容时必须明确报错，绝不继续展示旧 Host 数据。

流畅性验收采用可复现场景：Host 延迟 30 秒时，刷新后 250 ms 内出现忙碌状态和取消入口；请求等待期间导航、筛选输入与取消在 500 ms 内获得界面反馈；过期响应不能改变可见状态；收到 100 行响应后 1 秒内完成可交互呈现。固定 Windows runner 的容差和 flaky 治理由“固定 WPF 截图基线与 Windows CI 证据规则”继续决定。
