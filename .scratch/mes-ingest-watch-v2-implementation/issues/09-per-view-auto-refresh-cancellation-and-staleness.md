# 09 — 统一四视图自动刷新、取消与陈旧错误表达

**What to build:** 让概览、VISIBLE、GONE 和 IngestAlert 各自按用户偏好自动刷新，同时保持用户操作优先、单飞、不排队，并在超时、错误或取消后继续显示可信且明确标记时间的最后成功结果。

**Blocked by:** 03 — 完成概览健康结论与业务摘要; 05 — 完成独立 GONE TransportDemand 浏览; 07 — 完成 IngestAlert 浏览与非模态详情

**Status:** ready-for-agent

- [ ] 四个视图分别提供默认关闭的自动刷新开关和 10/30/60/300 秒间隔；只有当前可见视图运行计时器，切回已开启视图时立即刷新一次。
- [ ] 自动刷新到点但已有请求时跳过且不排队；手动刷新、翻页、查询、排序或页面切换取消旧请求并立即执行新的用户操作。
- [ ] 每次请求终止后重新等待完整间隔，手动刷新也重置计时；自动失败不立即重试且不做指数退避。
- [ ] 刷新当前页时保留成功窗口并在 250 ms 内显示忙碌和取消入口；等待期间导航、筛选输入和取消在 500 ms 内获得界面反馈。
- [ ] 用户主动取消显示中性“已取消”、保留成功窗口且不记录连接故障；导航取消无额外提示。
- [ ] 超时、网络、鉴权、解码和非 cursor 400 显示 endpoint、等待时长、最后成功时间、陈旧程度和 correlation id，并保持原已提交查询。
- [ ] 真实连接失败继续使用既有 WatchConnectionEvent 去重、恢复和有界脱敏日志；本地日志写入失败不得改变 HTTP 成功结果或阻塞刷新。
