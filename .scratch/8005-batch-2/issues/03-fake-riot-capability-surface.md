# 03 — 假 RIoT 扩能力面，合成对端支持三车

**做什么：** 把 L2 的合成装置扩到能承载批次 2 的四条能力轨。做完之后，引擎、命令面与
多车三件事都能在 L2 上取证，而不必等真装置或现场。

四项扩充：

1. **五个 `imap` 只读端点**——边表、站点、移除边、移除站点、`mapEdgeGroup`，供
   `RouteGraphSnapshot` 引擎取设计态与运行态。返回形状按 SDK 侧的自定义反序列化约定
   （snake_case、`s_node`／`e_node`、站点侧键名字面带点）。
2. **订单命令面**——`CANCEL`／`OrderHold`／`OrderContinue`／`HangContinue`／
   `triggerEmergency`／`cancelEmergency`。**只记录调用，不模拟业务后果**（规格第 14 节
   待办第 3 项明文如此）。记录要能支撑「该调用时调用了、参数正确、只调一次」这三条断言。
3. **多车种子**——假 RIoT 侧能同时呈现三台车的可派车状态与观测。
4. **合成车载端三实例**——`FakeOnboard` 支持同时跑三个会话。真装置多车不在本期
   （`slots-simulator` 的多实例支持本期不需要），合成对端够用。

**冲突边界：** 本票只动 `tools/` 下的合成装置目录与 L2 装置装配，不动 `src/` 与
`tests/` 下的产品代码与产品测试。

**前置：** 无，可立即开工。
