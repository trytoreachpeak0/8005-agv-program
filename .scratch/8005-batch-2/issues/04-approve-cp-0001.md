# 04 — 取得 `CP-0001` 批准

**做什么：** 走完需求变更提案 `CP-0001` 的批准路径，让 `RouteGraphSnapshot` 引擎与
五个 `imap` 只读端点获得需求依据。**这不是工程票，是批准动作**，批准人是用户本人
（完整产品规格 12.2 节点 2）。

提案含两条修订，只动两条：

- **修订项一 `REQ-0298` 重写**——目录与路网成为两份各自具名的产品事实。
  `MapStationCatalogSnapshot` 仍不承载 Edge，`RouteGraphSnapshot` 另行持有某张 Map 的
  完整有向站点图，由设计态与运行态合成。几何路网与动态交通状态仍排除。
- **修订项二 `REQ-0146` 增列五个 `imap` 只读端点**——边表、站点、移除边、移除站点、
  `mapEdgeGroup`。`removedEdgeDetail` 不批，引擎用不上。

**这张票卡住两条关键路径**：票 07（SDK 新增五个 Facade）与票 12（引擎）都不得在批准前
据修订文开工（规格 9.4）。它同时是整个批次 2 关键路径的起点。

批准前若要描述引擎相关工作，正确写法是「实施形态与基线 `REQ-0298` 原文存在一条已知且
已记录的偏离，偏离的处置见 `CP-0001`」，**不得写「符合 `REQ-0298`」**（规格 8.8 第 3 条）。
