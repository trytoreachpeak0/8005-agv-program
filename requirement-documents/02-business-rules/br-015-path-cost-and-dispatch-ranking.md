# BR-015 Path Cost and Dispatch Ranking 路径成本与派车排序权衡

## Rule Statement 规则内容

本系统在为待处理搬运任务选择 AGV、或对任务池中候选任务/任务集合进行排序时，可将**基于 RIOT 地图路网估算的最短路径成本**作为综合排序因子之一，与任务紧急程度及其他时间类指标一并权衡。本规则只定义路径成本如何计算、如何参与排序、以及与 RIOT 导航职责的边界；车辆硬性可分配条件仍以 [[br-002-agv-allocation-eligibility|BR-002]] 为准，本次派车任务范围仍以 [[br-001-dispatch-task-range|BR-001]] 为准。

### 1. 路径成本定义

1. 路径成本基于本系统本地缓存的 RIOT 地图路网快照（由 [[uc-045-sync-map-topology-from-riot|UC-045]] 同步）计算，不得用手填假路径或仅按直线欧氏距离替代（欧氏距离仅可在路网不可用时的降级策略中临时使用，见第 4 节）。
2. 单次评估的路径成本，默认取「车辆当前位置对应站点（或最近可解析站点）→ 本轮任务集合的首个取货/作业站点」在路网上的**最短路径长度或等价行驶成本**；若本轮任务集合含多个站点，是否叠加后续站间成本、以及如何折算顺路复合停靠，TBD（须可配置，确认前不得写死）。
3. 成本单位（米、边权、预计秒数等）、站点定位失败时的处理，以及车不在任何站点上时如何映射到图节点，TBD。

### 2. 与紧急度及其他时间指标的关系

路径成本只是 [[br-002-agv-allocation-eligibility|BR-002]] Candidate Ordering 中的一个因子，不得单独决定派车结果。排序须同时考虑（顺序与权重仍以 BR-002 为准，公式 TBD）：

1. 任务类型优先级（含 [[br-014-transport-task-types-and-fixed-stations|BR-014]] 第 5 类最高优先）。
2. 无车辆响应升级。
3. 任务等待时长与 MES 事件时间等时间类指标。
4. **本规则定义的路径成本**（对应 BR-002 中的「距离或预计到达成本」）。
5. 电量、仓位匹配、车辆调度权重等其余因子。

已确认的硬优先（如第 5 类）不得被「路径更近」覆盖；路径近只影响同优先级或可比较区间内的相对排序。

### 3. 与 BR-001、RIOT 导航的边界

1. **与 BR-001**：某任务是否属于「本次派车任务范围」，只看是否已进入该任务集合，**不看**与 AGV 当前位置的路径远近。路径成本仅用于分配/排序权衡，不改变范围判定。
2. **与 RIOT**：本系统向 RIOT 下发移动任务时**只能指定目的地（目标站点）**，不能指定途经中间路程；实际路径规划、交通管制与运动控制仍由 RIOT 负责。本系统计算最短路径成本的前提假设是：RIOT 在仅指定目的地时通常按最短（或等价最优）路径执行，因此本地最短路成本可作为「预计行驶代价」的估计，用于派车权衡，**不替代、不下发、不覆盖** RIOT 的真实导航路径。
3. 本系统不得向 RIOT 下发途经点序列来「强制」本地算出的路径；若业务上未来需要途经约束，须另行确认 RIOT 能力并修订本规则与 [[uc-008-dispatch-move-order-to-riot|UC-008]]。

### 4. 路网不可用时的降级（须明确，默认如下）

1. 若本地路网快照缺失、过期超出允许阈值、或起终点在图中不可达，本轮分配**仍可继续**，但不得使用本规则的最短路径成本参与排序；应记录「路径成本未启用」原因，并仅按 BR-002 中其余已可用因子排序。
2. 是否允许用直线距离等弱替代、过期阈值分钟数、以及是否在路网长期不可用时告警，TBD（可配置）；确认前实现不得把弱替代伪装成「已按 RIOT 路网最短路径」写入审计。

### 5. 评分公式与配置

路径成本在综合评分中的权重、与时间类指标的归一化方式、并列规则，以及任务池内「先选哪批任务再选哪台车」与「先选车再匹配近任务」的评估顺序，均仍为 TBD，须可配置。确认前不得将临时数值固化为不可配置的正式调度策略（与 BR-002 既有约束一致）。

## Rationale 制定原因

RIOT 接口形态限制本系统只能指定目的地，无法在下发时规划途经；同时 RIOT 侧实际行驶又通常走最短路径。若本系统在任务池派发时完全不考虑地图路径远近，容易把远距离低紧急任务与近距离高紧急任务混排，或浪费空闲车辆。本地只读同步路网并估算最短路径成本，可以在不侵入 RIOT 导航职责的前提下，把「路程远近」变成可审计的排序因子，并与紧急度、等待时长等业务指标一起权衡。

## Source 来源

2026-07-14 需求确认：从 RIOT 读取地图与路径；派发时按任务远近（并与紧急程度及其他时间指标）权衡；RIOT 只能指定目的地且通常走最短路径，故用任务池最短路径成本作为派发权衡值。
