## Use Case 列表

UC-01: 装载产品/物料到AGV
Actor: 装片设备操作员（R-01）/ 其他站点操作员（按场景替换为对应角色，见上方角色清单）
Trigger： AGV到达指定位置
基本流程：
1. 操作员扫描产品/物料工单
2. 系统显示可用仓位
3.

可能的 user case（对应场景见 `简易需求文档.md` 5.2 节，涉及角色见上方角色清单）：
- 装片完工送烘烤：R-01 → R-02
- 装片完工送焊线氮气柜：R-01 → R-03
- 焊线/键合完工送关卡：R-06/R-07 → R-04
- 焊线/键合完工送 AOI：R-06/R-07 → R-08
- 清洗间送焊线机台：R-05 → R-06
- 氮气柜送焊线/键合机台：R-03 → R-06/R-07

维护类 user case：待补充（涉及 R-11 设备/电气维护人员、R-12 IT/软件维护人员、R-13 AGV 运维/调度管理员，如故障处理、配置维护、异常恢复等场景）
