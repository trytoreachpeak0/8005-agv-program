# 8005 多仓位 AGV
<!-- 8005是公司的项目编号 -->
## 1. 需求背景
### 1.1 需求名称
宿迁长电科技半导体封装前线多仓位 AGV 物料搬运需求
### 1.2 当前问题
目前前线物料主要依靠人工搬运，搬运频次高、效率低，也不便于统一追踪任务状态。
### 1.3 目标
使用多仓位 AGV 承担装片、焊线、烘烤、氮气柜、AOI 等区域之间的物料转运，减少人工搬运，提高现场周转效率。
### 1.4 使用区域
宿迁长电科技老厂前线装片区域和焊线区域，包含烘烤间、氮气柜、AOI、清洗架等相关点位。

## 5. 业务流程与场景描述

### 5.1 基本流程

系统从 MES 获取待搬运物料，形成本地任务，再根据车辆空闲情况派发给 RIOT。AGV 到达起点后，由现场人员扫码或手输 sublot，系统核验通过后打开对应仓位，装篮完成并确认电子锁、光幕状态正常后，AGV 才能前往终点。

整体流程如下：

1. 服务器定时查询 MES 待搬运数据。
2. 按 `product_lot + machine_no + finish_time` 或 MES 事务 ID 做本地去重。
3. 本地没有记录时创建新任务；已有记录时按本地任务状态处理。
4. 任务为 `New` 且 AGV 空闲时，向 RIOT 下发移动任务。
5. AGV 到达起点后，操作员扫码或手输 sublot。
6. 系统核验 sublot、搬运类型、工序和任务状态。
7. 核验通过后打开指定仓位，操作员装篮并确认完成。
8. 电子锁和光幕状态正常后，AGV 发车到终点。
9. 卸车完成后，系统回写 MES 或提示 OP/PDA 完成后续操作。
10. 任务关闭并保留历史记录。

任务进入 `Missing`、`Exception`、`Done`、`Cancelled` 后不再自动重派。即使 MES 仍能查到该批物料，也需要人工确认后再处理，避免现场物料和系统记录不一致时反复叫车。

### 5.2 各搬运场景

#### 5.2.1 装片完工送烘烤

该场景用于装片设备完工后的物料送烘烤间。MES 中 `step` 为「装片烘烤」或「装片压力烘烤」、`task='入站'` 且未关闭时，系统可创建搬运任务。

流程要点：

1. 执行 IT 提供的 `送烘箱的芯片装片完工.sql` 查询待送物料。
2. 根据 MES 返回的机台区域 `area` 找到 AGV 地图站点。
3. RIOT 调度 AGV 到装片设备。
4. 到位后扫码或手输 sublot，按 `moveType='BAKE'` 做装料核验。
5. 核验通过后装入空仓位。
6. AGV 送至烘烤间。
7. 卸车后回写 MES 或提示 OP 做入站操作。

旧程序中该流程通过 `CallAGV2ZPEQP` 查询区域、映射 `StationInfo`、调用 `ADDORDER` 下单，并在完成后更新 `FW_FUNCTIONTEST_AVG.tag=1`。新系统不再依赖该表做防重，任务是否重复以本地任务状态为准。

#### 5.2.2 装片完工送焊线氮气柜

该场景用于装片完工后，需要进入焊线或键合工序前的氮气柜暂存。MES 中 `step` 为「焊线」或「键合」、`task='入库'` 且未关闭时，系统可创建搬运任务。

流程要点：

1. 执行 IT 提供的 `送装片的芯片装片完工.sql` 查询待送物料。
2. 根据装片机台和焊线氮气柜配置确定起点、终点站点。
3. RIOT 调度 AGV 到装片设备。
4. 到位后扫码或手输 sublot，按 `moveType='WIRE_BOX'` 做装料核验。
5. 核验通过后装篮并锁仓。
6. AGV 送至焊线氮气柜。
7. 卸车后回写 MES 或提示 OP/PDA 完成入库。

#### 5.2.3 焊线/键合完工送关卡氮气柜

该场景用于焊线或键合完工后的物料送关卡氮气柜。具体 MES 查询条件、核验参数和回写方式需 IT 确认。

流程要点：

1. MES 查询到焊线/键合完工待送任务。
2. 系统根据焊线/键合机台找到起点站点。
3. 终点取关卡氮气柜对应站点。
4. AGV 到位后扫码或手输 sublot。
5. 核验通过后装车，送至关卡氮气柜。
6. 卸车后按现场流程回写或提示人工处理。

#### 5.2.4 焊线/键合完工送 AOI

该场景用于焊线或键合完工后需要送 AOI 检查的物料。MES 查询条件、核验参数和回写方式需 IT 补充。

流程要点：

1. MES 查询到焊线/键合完工送 AOI 任务。
2. 系统取焊线/键合机台为起点，AOI 设备为终点。
3. AGV 到起点后，操作员确认物料并扫码。
4. 核验通过后装车。
5. AGV 送至 AOI 设备。
6. 卸车后提示 OP 完成交接或执行 MES 回写。

#### 5.2.5 清洗间送焊线机台

该场景用于清洗完工物料送焊线机台。MES 查询条件、核验参数和回写方式需 IT 补充。

流程要点：

1. MES 查询到清洗完工送焊线任务。
2. 起点为清洗完工物料架，终点为目标焊线机台。
3. AGV 到清洗架后，操作员扫码或手输 sublot。
4. 核验通过后装车。
5. AGV 送至焊线机台。
6. 卸车后提示 OP 接收或执行 MES 回写。

#### 5.2.6 氮气柜送焊线/键合机台

该场景用于焊线区氮气柜中的物料送至焊线或键合机台。MES 中存在氮气柜送焊线/键合任务时，系统可创建搬运任务。具体 MES 查询条件、核验参数和回写方式需 IT 补充。

流程要点：

1. MES 查询到氮气柜送焊线/键合任务。
2. 起点为焊线区氮气柜，终点为目标焊线/键合机台。
3. AGV 到氮气柜后，操作员扫码或手输 sublot。
4. 核验通过后装车。
5. AGV 送至目标焊线/键合机台。
6. 卸车后提示 OP 接收或执行 MES 回写。

### 5.3 装载与调度原则

- 现场共有 3 台 AGV，由 RIOT 统一调度。
- 单台 AGV 有 8 个仓位，最多同时装 8 个金属篮。
- 同一批次、同起点、同终点方向的物料优先合并装车。
- 不同搬运类型或终点差异较大的物料不建议混装。
- 待搬篮数超过 8 个时，按多趟任务处理。

## 7. 接口与通信需求

### 7.1 系统连接关系

系统涉及上位机、IO 模块、服务器、RIOT 和 MES。上位机负责现场操作和仓位控制；服务器负责任务、MES 和 RIOT 调度；RIOT 负责 AGV 行驶；MES 提供业务数据。

| 链路 | 作用 |
| ---- | ---- |
| 上位机 ↔ IO 模块 | 读取电子锁、光幕信号，控制仓位开关锁 |
| 上位机 ↔ 服务器 | 同步任务、提交扫码结果、上报仓位状态 |
| 服务器 ↔ RIOT | 下发 AGV 移动、取消、充电等任务 |
| 服务器 ↔ MES | 查询待搬运物料，执行装料核验和完工回写 |

### 7.2 上位机 ↔ IO 模块

| 项目 | 内容 |
| ---- | ---- |
| 连接方式 | 通过交换机接入现场局域网 |
| 协议 | 康耐德 IO 通信协议，具体协议和端口由供应商确认 |
| DI | 电子锁开/关反馈、光幕状态，点位表待确认 |
| DO | 电子锁控制输出，点位表待确认 |
| 异常处理 | IO 通信中断时禁止开锁，并在上位机提示 |

### 7.3 上位机 ↔ 服务器

| 数据 | 方向 | 说明 |
| ---- | ---- | ---- |
| 任务列表 | 服务器 → 上位机 | 下发待执行、执行中、异常任务 |
| 扫码/手输结果 | 上位机 → 服务器 | 提交 sublot 及对应仓位 |
| 仓位状态 | 上位机 → 服务器 | 上报电子锁、光幕和占用状态 |
| 告警信息 | 服务器 → 上位机 | 推送 MES、RIOT、任务异常 |

通信方式可采用 REST API 或 WebSocket，接口路径、鉴权方式和字段格式后续由开发确认。

### 7.4 服务器 ↔ RIOT

已知 RIOT 支持 HTTP 接口，下列接口需结合 RIOT 文档确认：

| 接口 | 用途 |
| ---- | ---- |
| 创建移动任务 | 指定 AGV 和目标站点 |
| 查询任务状态 | 获取是否到达、执行中或失败 |
| 取消任务 | 人工取消或异常时停止任务 |
| 充电任务 | 低电量或人工触发充电 |

旧程序中的 `ADDORDER(Station_id)` 可作为理解参考，新系统应改为调用 RIOT HTTP 接口。

### 7.5 服务器 ↔ MES

服务器通过 Oracle 访问 MES。任务发现、sublot 核验、完工回写均由服务器侧统一处理，上位机不直接访问 MES。

| 类型 | 说明 |
| ---- | ---- |
| 查询 | 使用 IT 提供的 SQL 查询待搬运物料 |
| 核验 | 使用 `合并版.sql` 校验 sublot 当前状态 |
| 回写 | 搬运完成后按场景回写，具体 SQL 待 IT 确认 |
| 映射 | 本地维护 MES 区域/机台与 AGV 站点关系 |

## 8. 异常与安全处理

### 8.1 任务异常

| 状态 | 说明 | 处理方式 |
| ---- | ---- | -------- |
| Missing | AGV 到机台后未找到应搬物料 | 告警 OP/班组长/中控，不自动重派 |
| Exception | MES、RIOT、IO 或核验过程异常 | 记录日志，等待人工处理 |
| Cancelled | 人工取消任务 | 停止后续调度，记录取消操作与逐仓清空证据 |
| Done | 搬运完成 | 归档任务历史 |

异常任务恢复时，需要记录操作人和处理原因。

### 8.2 装料核验异常

装料前调用 `合并版.sql`，根据返回值处理：

| 返回值 | 说明 | 处理 |
| ------ | ---- | ---- |
| OK | 校验通过 | 允许装料 |
| NG_LOT_NOT_FOUND | MES 未找到该 sublot | 提示核对条码 |
| NG_LOT_CLOSED | sublot 已关闭 | 禁止装料 |
| NG_STEP_ERROR | 工序不符合搬运类型 | 禁止装料 |
| NG_TASK_ERROR | task 不符合搬运类型 | 禁止装料 |
| NG_MOVE_TYPE_ERROR | 搬运类型参数错误 | 提示联系管理员 |

默认不允许跳过核验装料。现场如需特批，应由班组长确认并记录。

### 8.3 仓位安全

- 装料前确认 AGV 停稳、仓位可用。
- 开锁、关锁均以 IO 反馈为准。
- 光幕异常或仓位未关锁时，不允许发车。
- 装卸过程中不下发新的移动指令。
- 急停后停止当前任务，并提示现场人员确认物料和仓位状态。

### 8.4 通信异常

| 异常 | 处理方式 |
| ---- | -------- |
| MES 断连 | 暂停新建任务，保留当前任务状态，恢复后继续轮询 |
| RIOT 断连 | 禁止新下发移动任务，已下发任务超时后转异常 |
| IO 断连 | 禁止开锁，已开锁仓位需人工现场确认 |
| 站点未配置 | 提示维护站点映射，不下发 AGV 任务 |
| 服务器断连 | 上位机显示离线，仓位保持锁闭 |

### 8.5 日志记录

系统需记录以下内容：

- 扫码、手输、装料、卸料、取消、告警确认等操作记录。
- MES、RIOT、IO 的请求和返回信息。
- 任务状态变化、派车时间、到达时间、核验结果、回写结果。

日志保留时间由后续运维要求确定。

### 8.6 数据安全

- MES SQL 使用参数化方式执行，不拼接用户输入。
- 数据库连接信息不明文暴露在界面或普通配置中。
- 上位机与服务器通信在厂区内网中运行，必要时增加 HTTPS 或网络隔离。
