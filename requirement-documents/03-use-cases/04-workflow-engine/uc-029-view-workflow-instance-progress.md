# UC-029 查看流程实例进度

## 描述

R-12、R-13 和生产流程管理员 R-14 以只读方式查询流程实例进度。系统展示实例绑定的模板及版本、当前步骤、已完成/跳过/失败步骤、等待原因、业务任务/AGV/RCS 编号和审计记录，并把来自 MES、RCS/RIOT、AGV 或 IO 的过期外部状态明确标记为“过期”，不得将旧值表现为当前状态。

本 UC 不允许修改模板、任务、流程、流向、优先级或异常处置。

## 触发条件

1. 用户按流程实例、业务任务、MES 标识、AGV、RCS/RIOT 移动任务编号、模板版本、状态或时间范围发起查询。
2. 用户从告警、业务任务或 AGV 详情进入关联流程实例。
3. 用户刷新正在运行、等待或异常的实例进度。

## 前置条件

1. 用户使用个人账号登录，并具有流程实例只读查看权限。
2. 用户的数据访问范围已经确定；R-14 不具备配置或异常处置权限。
3. 流程实例、步骤状态、模板快照、业务关联和审计存储可查询。
4. 外部状态的来源时间、接收时间及各类型有效期阈值可取得；无法确定新鲜度时按未知/过期展示。

## 后置条件

1. 用户看到与其权限范围一致的流程实例快照和步骤时间线。
2. 外部实时状态显示来源、采样/事件时间、最近更新时间及“当前/过期/未知”标记。
3. 查询、查看详情及导出行为被记录；流程、业务任务、模板和设备状态不被修改。
4. 敏感凭据、完整请求体等不应展示的数据被脱敏或以安全引用替代。

## 假设

1. 页面展示的是各系统最后已确认并持久化的状态，不保证外部系统始终在线。
2. 不同外部状态可使用不同的新鲜度阈值，具体数值由预置配置管理。
3. 审计记录采用追加写入；本 UC 不提供编辑或删除入口。

## 正常流程

### 29.0

1. 用户进入流程实例查询页面。
2. 系统根据用户角色和数据范围展示可访问的实例列表。
3. 用户输入一个或多个筛选条件：流程实例、业务任务、MES/SUBLOT 标识、AGV 编号、RCS/RIOT 移动任务编号、模板/版本、流程状态、步骤状态或时间范围。
4. 系统返回匹配实例，并区分流程实例状态与业务任务状态。
5. 用户打开一个实例详情。
6. 系统展示模板快照信息：
   6.1 `templateId`、`templateVersionId`、版本号、目录版本和内容校验值。
   6.2 原匹配输入、匹配结果，以及存在时的授权手动覆盖摘要。
7. 系统按固定顺序展示步骤时间线：
   7.1 当前步骤及开始/等待时间。
   7.2 已完成 `Succeeded`、已跳过 `Skipped`、失败 `Failed` 的步骤。
   7.3 `WaitingExternal`、`RetryWaiting`、`Suspended` 的原因、截止时间和已尝试次数。
8. 系统展示关联标识，包括业务任务、MES 事务/SUBLOT、AGV、仓位、站点、RCS/RIOT 移动任务、外部请求和事件 ID。
9. 系统展示每次步骤尝试的脱敏输入摘要、标准化输出、错误码、幂等/对账摘要、状态迁移和时间。
10. 系统展示异常、告警、自动重试及经授权人工处置的审计记录。
11. 对外部状态，系统比较来源时间/接收时间和预置有效期：
   11.1 有效期内明确标记“当前”，并显示时间和来源。
   11.2 超过有效期明确标记“过期”，显示已过期时长，不把该值用于当前安全结论。
   11.3 时间缺失、来源不可验证或读取失败时标记“未知”。
12. 系统记录本次查看行为，不执行任何状态变更。

## 备选流程

### A3.1 从关联对象反向查询

1. 用户从业务任务、AGV、告警或 RCS/RIOT 编号进入。
2. 系统展示该对象关联的一个或多个流程实例及各自独立状态。
3. 用户选择具体实例后继续第 5～12 步。

### A12.1 导出只读进度与审计

1. 具有导出权限的用户选择时间范围和字段。
2. 系统按当前数据权限生成带导出时间、筛选条件和状态新鲜度标记的文件。
3. 导出内容脱敏，不包含凭据、任意请求体或超出权限的数据，并记录导出审计。

### A10.1 查看异常处置入口

1. R-12/R-13 查看失败或暂停实例时，系统可显示“转到异常处置”链接。
2. 跳转前不改变任何状态；后续操作完全遵循 UC-028。
3. R-14 不显示可执行处置按钮，仅可查看已发生的处置记录。

## 异常流程

以下异常与 Normal/Alternative Flow 的对应步骤关联：

- E2.1 用户无权访问。
- E4.1 流程或业务状态数据不完整。
- E6.1 模板快照无法验证。
- E8.1 关联标识缺失或冲突。
- E10.1 审计记录暂不可用。
- E11.1 外部状态过期或未知。
- EA12.1 导出失败或范围过大。

### E2.1 用户无权访问

1. 用户无查看权限或请求超出其数据范围。
2. 系统拒绝访问，不泄露实例是否存在，并记录安全审计。

### E4.1 流程或业务状态数据不完整

1. 某一状态无法读取或状态记录相互不一致。
2. 系统分别标记受影响字段为“未知/数据不一致”，不把业务任务状态复制成流程状态或反向推断。
3. 系统记录诊断告警，但页面保持只读。

### E6.1 模板快照无法验证

1. 模板版本不存在、内容校验值不一致或步骤目录版本无法解释。
2. 系统显示“快照完整性异常”，不改用模板当前版本替代，并关联告警/诊断记录。

### E8.1 关联标识缺失或冲突

1. 业务任务、AGV、RCS/RIOT 编号或外部事件关联缺失/不唯一。
2. 系统明确显示缺失或冲突项，不猜测关联关系，并提供可追踪的错误编号。

### E10.1 审计记录暂不可用

1. 审计查询失败或部分存储不可达。
2. 系统标记“审计数据不完整”，显示最后成功读取时间，不将“无记录”误表示为“未发生操作”。

### E11.1 外部状态过期或未知

1. MES、RCS/RIOT、AGV 或 IO 状态超过有效期，或缺少可信时间/来源。
2. 系统使用醒目标记显示“过期”或“未知”，保留原值仅供历史参考。
3. 页面不得据此显示“当前安全”“当前可分配”或其他实时结论。

### EA12.1 导出失败或范围过大

1. 请求超出权限、预置条数/时间范围，或生成文件失败。
2. 系统拒绝或缩小导出，记录原因；不得返回未脱敏的临时数据。

## 备注

- R-12/R-13 在本 UC 中也仅执行查看；其维护或异常处置权限必须通过对应 UC 的独立入口使用。
- “过期”是数据新鲜度结论，不等于外部对象实际异常；“未知”也不得解释为正常。
- 若一个业务任务关联多个阶段性流程实例，页面必须分别展示每个实例的模板快照、状态和审计。
