# UC-030 维护用户账号

## 描述

具有用户管理权限的 R-12 在 AGV 系统中创建、查询、修改、启用或停用管理配置端的本地个人账号。系统保证账号标识唯一、账号状态可追溯，并在停用账号时阻止其继续建立或保留管理会话。

本 UC 不创建或绑定现场操作员工牌。放料、收料、取消订单等现场操作仍由操作员刷工牌，AGV 系统通过 MES 获取人员身份和岗位权限；MES 工牌身份与本地管理账号彼此独立。

## 触发条件

1. 新的管理配置端人员需要本地账号。
2. 现有账号的姓名、联系方式或说明需要修改。
3. 人员离岗、调岗、临时冻结或恢复任职，需要停用或启用账号。
4. R-12 需要查询账号状态、角色或最近登录信息。

## 前置条件

1. R-12 已通过 [[uc-033-login-to-management-console|UC-033]] 登录，且具有用户查看或用户维护权限。
2. 本地用户、角色授权和审计服务可用。
3. 被修改的账号存在且未被物理删除；创建账号时拟用登录名尚未占用。
4. 执行启用、停用或关键身份字段修改时，系统能够重新校验操作者当前权限。

## 后置条件

1. 创建成功后生成唯一、可引用的本地用户标识，账号初始状态明确。
2. 修改成功后仅允许维护的账号资料发生变化，历史审计中的人员标识不被改写。
3. 停用成功后账号不能新建会话，现有会话被撤销；其历史操作和授权记录继续保留。
4. 操作人、目标账号、动作、原因、变更前后内容、时间和结果被写入不可由本 UC 编辑的审计记录。

## 假设

1. 本地管理账号用于管理配置端，不替代 MES 的员工主数据或现场工牌认证。
2. 密码或其他本地凭据按系统安全策略保存；任何页面和审计日志均不记录明文凭据。
3. 人员姓名等展示信息可修改，但系统内部用户标识创建后保持不变。

## 正常流程

### 30.0

1. R-12 进入用户管理页面。
2. 系统按操作者权限展示本地账号列表、状态、已分配角色和最近登录摘要。
3. R-12 选择新建账号，填写登录名、人员姓名、联系方式或说明等必要资料。
4. 系统校验字段格式、登录名唯一性和禁止使用的保留标识。
5. R-12 确认创建。
6. 系统生成不可变的本地用户标识和初始凭据设置流程，账号在凭据设置完成前不得登录。
7. R-12 可转到 [[uc-032-assign-user-roles|UC-032]] 为账号分配角色。
8. 系统保存账号并记录创建审计，不在页面、通知或审计中暴露明文凭据。

## 备选流程

### A3.1 修改账号资料

1. R-12 选择已有账号并修改允许维护的展示资料。
2. 系统展示变更前后差异并校验字段。
3. R-12 确认后，系统保存修改并记录审计；内部用户标识和历史记录保持不变。

### A3.2 停用账号

1. R-12 选择启用中的账号，填写非空停用原因。
2. 系统展示该账号的角色、活动会话及相关影响。
3. 系统重新校验 R-12 的用户维护权限，并确认停用后仍至少有一个可用的用户与权限管理员账号。
4. 系统原子地停用目标账号、撤销其活动会话并记录审计。

### A3.3 重新启用账号

1. R-12 选择已停用账号，核对人员仍有管理配置端访问需要。
2. 系统重新校验账号标识、现有角色状态和凭据状态。
3. R-12 填写原因并确认，系统启用账号；过期或失效凭据须先重设。

## 异常流程

以下异常与 Normal/Alternative Flow 中的对应步骤关联：

- E4.1 登录名重复、字段无效或使用保留标识。
- E6.1 初始凭据设置失败。
- EA3.2.1 停用最后一个可用管理员账号。
- EA3.2.2 目标账号状态已经变化。
- E8.1 账号或审计事务失败。

### E4.1 登录名重复、字段无效或使用保留标识

1. 登录名已存在、格式不合法，或与系统保留标识冲突。
2. 系统拒绝创建并指出可修正字段，不泄露其他账号的敏感信息。

### E6.1 初始凭据设置失败

1. 凭据初始化或安全通知失败。
2. 系统不得使账号进入可登录状态；保留安全的待设置状态并记录失败原因。

### EA3.2.1 停用最后一个可用管理员账号

1. 停用将导致系统不存在可用的用户与权限管理员。
2. 系统拒绝停用并提示先建立另一名具备相应权限的可用账号。

### EA3.2.2 目标账号状态已经变化

1. 提交前目标账号已被其他管理员修改、停用或启用。
2. 系统拒绝覆盖并要求刷新后重新确认。

### E8.1 账号或审计事务失败

1. 账号保存、状态变更、会话撤销或审计任一写入失败。
2. 系统回滚本次操作，不留下部分生效状态，并提供可追踪错误编号。

## 备注

- 本 UC 只管理 AGV 管理配置端本地账号，不提供操作员工牌导入、绑定或授权入口。
- 账号不物理删除；离岗人员通过停用处理，以保留历史操作主体和审计链。
- 用户管理权限本身由 UC-031 定义，并通过 UC-032 授予账号。

## 关联用例

定义可分配给本地账号的角色及权限。
- [[uc-032-assign-user-roles|UC-032]]：为本 UC 创建的账号授予或撤销角色。
- [[uc-033-login-to-management-console|UC-033]]：使用启用中的本地账号登录，并在账号停用时终止会话。
查询账号创建、修改、启停及失败操作的审计记录。
