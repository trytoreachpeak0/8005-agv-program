# UC-020 维护 AGV 调度配置

## 描述

管理员维护已接入 AGV 的本地业务和任务分配配置，包括本地名称、RCS/RIOT 车辆 ID 映射、车型、服务区域、最低接单电量、调度权重及维护备注。仓位数量、位置和规格不在本 UC 中维护——它们由 [[uc-019-register-agv-from-rcs|UC-019]] 接入时绑定的多仓位 AGV 模型版本快照决定，本 UC 只能只读展示，不提供修改入口，也不提供更换已绑定型号/版本的入口（见 [[br-008-agv-slot-model-versioning|BR-008]] 第 3 条）；确需更换型号，必须先通过 [[uc-021-archive-agv|UC-021]] 归档该 AGV，再以正确型号重新执行 UC-019 接入。

为避免配置变化影响正在执行或等待装卸的业务，目标车辆必须已禁用、本地无未完成作业且所有仓门关闭，配置才允许保存。

## 触发条件

管理员需要修正或调整某台 AGV 的本地业务配置。

## 前置条件

1. 目标 AGV 已通过 [[uc-019-register-agv-from-rcs|UC-019]] 接入且未归档。
2. 目标 AGV 已处于“已禁用”，不存在“禁用待生效”状态。
3. 目标 AGV 本地无未完成任务或站点作业，所有仓门均确认关闭。
4. 管理员具有 AGV 配置维护权限。

## 后置条件

1. 新配置保存并用于后续 [[uc-023-allocate-transport-tasks-to-agv|UC-023]]。
2. AGV 保持“已禁用”，不会因保存配置而自动启用。
3. 操作人、修改时间及修改前后值被记录到审计日志。

## 假设

1. 本 UC 维护本地业务配置，不修改 RCS/RIOT 中的车辆本体参数。
2. RCS/RIOT 车辆 ID 原则上不应频繁修改；修改时必须重新校验唯一性和外部存在性。
3. 本 UC 展示的仓位编号、位置、规格均来自 UC-019 接入时冻结的模型版本快照，本 UC 不重新读取型号当前最新版本，也不提供任何编辑该快照的入口。

## 正常流程

### 20.0

1. 管理员在 AGV 列表中选择目标车辆并进入配置界面。
2. 系统核验车辆未归档、已禁用、本地无未完成作业且所有仓门关闭。
3. 系统展示当前配置及其最近修改记录，包括只读展示的绑定型号、版本号及仓位结构（编号、位置、规格）。
4. 管理员修改身份映射、车型、服务区域、电量阈值、调度权重或备注（不包含仓位结构，见 Assumption 第 3 条）。
5. 系统校验 RCS/RIOT 车辆 ID、配置完整性、数值范围和内部一致性。
6. 系统展示修改前后差异，管理员确认保存。
7. 系统保存新配置，记录审计日志，并提示车辆仍处于禁用状态。

## 备选流程

### A4.1 仅修改备注

仅修改不影响任务分配的维护备注时，仍记录审计日志；是否可免除“已禁用”条件 TBD，当前按正常流程处理。

## 异常流程

### E2.1 车辆未完全停用

1. 车辆未禁用、处于禁用待生效，或存在本地未完成作业。
2. 系统拒绝进入可保存状态，提示先完成作业并通过 [[uc-013-enable-disable-agv|UC-013]] 禁用。

### E2.2 仓门或安全状态不满足

1. 任一仓门打开，或仓门、光幕、安全状态未知/异常。
2. 系统采用 fail-closed，拒绝保存影响调度的配置并提示处理现场状态。

### E5.1 配置冲突

1. RCS/RIOT 车辆 ID 重复、外部车辆不存在，或服务区域等配置不合法。
2. 系统拒绝保存并显示具体冲突项。

## 备注

- 仓位规格、载重（来自绑定的模型版本快照）和服务区域是任务分配的硬约束；电量阈值和调度权重参与候选过滤或排序。
- 配置版本回滚机制 TBD；当前至少保留完整变更审计。
- 本 UC 的"最低接单电量"与 [[uc-037-maintain-agv-charging-strategy-configuration|UC-037]] 新增的"触发充电阈值"/"充电完成阈值"是两个独立配置项，不合并维护：前者回答"这台车该不该继续接新的搬运任务"，后者回答"这台车该不该去充电、充到多少算完成"；两者数值可以相同，也可以不同，具体数值关系 TBD。
- 经与用户确认新增：仓位数量/位置/规格自 UC-020 中移除，改为只读展示 [[uc-038-maintain-agv-slot-model|UC-038]] 型号版本快照的内容；本 UC 不提供修改仓位结构或更换已绑定型号/版本的能力，具体原因和替代路径（先归档再重新接入）见 [[br-008-agv-slot-model-versioning|BR-008]]。
