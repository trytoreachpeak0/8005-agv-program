# DR-010 DO 控制模式——按点位独立配置电平/脉冲，锁状态镜像 DO 电平

## Decision 决策

1. **按 DO 点位独立配置，不是整机全局唯一模式**：每个 DO 点位除地址外，还可以设置 `control_mode`（Level / Pulse），以及 Pulse 模式下的脉冲时长，与 [[fr-001-configurable-slot-count-and-io-mapping|FR-001]] 的点位地址映射同层维护。
2. **锁状态（DI 反馈）直接镜像 DO（开锁指令）的当前电平值**：DO=1（True）→ 锁状态=解锁；DO=0（False）→ 锁状态=锁定，不论这个 0 是主系统显式写的（电平模式），还是模拟器在脉冲超时后自动写的（脉冲模式）。
3. **配置值是默认值，运行时寄存器值优先**：配置文件为每个 DO 提供默认工作模式和默认脉冲宽度；进程运行期间，主系统通过 Modbus 写入的工作模式/脉冲宽度寄存器立即成为该点位的有效值。完整 reset 才把运行时值恢复为配置默认值，规则见 [[dr-015-do-power-on-state-vs-reset|DR-015]]。
4. **脉冲允许重触发**：Pulse 模式的 DO 在计时未结束时再次收到有效的置 1 写入，应从该次写入时刻重新开始完整脉冲计时，而不是忽略重触发或沿用剩余时间。
5. **并发粒度以仓位为界**：同一仓位的命令严格串行，保持状态迁移顺序确定；不同仓位可并行执行。涉及多个点位的单次 Modbus 批量写按 [[dr-005-modbus-protocol-fidelity|DR-005]] 原子提交，不能让外部观察到半批状态。

## Rationale 理由

背景：现场仓位锁是电磁铁，DO 通电（1）锁打开，断电（0）电磁铁没电锁自动闩上（用户已确认）。现场驱动该 DO 的 IO 模块可能是电平输出，也可能是脉冲输出（脉冲继电器模块，工业现场常见，短时驱动后模块自身自动复位）。

1. 按点位独立配置而不是整机全局唯一模式，是为了与项目一贯的"不写死"风格保持一致（参考 [[dr-004-configurable-slot-count|DR-004]] 仓位数量可配置、[[dr-005-modbus-protocol-fidelity|DR-005]] 点位映射可配置的同一思路）：以后如果出现除"开锁指令"外的其他 DO 点位，各自可以有不同的硬件驱动方式，不需要改代码。
2. 锁状态镜像 DO 电平而不是独立维持的一次性触发动作状态，是因为电磁锁的物理特性决定了锁的开合完全跟随通电与否；这一点对脉冲模式尤其重要——脉冲模式下 DO 会在脉冲时长后被模拟器自动复位为 0，如果锁状态是独立的动作状态而不跟随 DO 电平，就无法真实还原"主系统没有正确处理脉冲超时复位、导致锁意外重新闩上"这类需要暴露给主系统测试的硬件特性。
3. 默认值与运行时值分层，既允许用配置得到可重复的启动/重置基线，也保留主系统在联调期间真实修改模块参数的能力；重触发重启计时与常见脉冲输出模块行为一致，并能消除同一点位并发计时器的歧义。
4. 同仓位串行保证"开门→放料→关门"不被竞争请求打乱，不同仓位并行则符合多个物理仓位可同时操作的事实。

## Alternatives Considered 备选方案

- 曾考虑只支持电平控制，做成整机唯一的固定行为，更简单——因用户澄清现场 IO 模块驱动方式可能是脉冲输出，且不同 DO 点位以后可能需要不同方式，未采纳。
- 曾考虑把"开锁"继续建模为独立于 DO 电平的一次性触发动作（边沿触发后由状态机单独维持锁状态）——因无法真实还原电磁锁"断电即闩锁"的物理特性，尤其是脉冲模式下的自动复位场景，未采纳。
