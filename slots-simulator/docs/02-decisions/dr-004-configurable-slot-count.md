# DR-004 仓位数量——可配置

## Decision 决策

仓位数量通过配置决定，不写死，也不设置一个脱离部署环境的固定软件数量上限。

"不设置固定上限"不等于无限接受：加载配置时必须严格校验仓位 ID 唯一性、布局坐标容量、模块/通道引用、模板声明的 DO/DI 硬件容量、监听端口冲突，以及实现定义并文档化的进程资源预算。超出硬件边界或当前主机可承载资源时应整体拒绝配置并返回明确错误，不得截断、静默忽略或部分加载。

## Rationale 理由

术语表记录当前一台 AGV 是 8 个仓位，但避免模拟器和某个具体柜型强绑定，方便未来测试不同配置。实际可承载规模同时受模块模板的物理通道数和运行主机资源约束，因此用显式边界校验比任意写死一个全局数量更准确。

## Alternatives Considered 备选方案

曾考虑先写死一个固定数量（比如 4 个），够用了再改；用户选择直接做成可配置。
