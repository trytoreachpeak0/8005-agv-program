## 4. 功能码支持矩阵

| 功能码 | 名称 | 支持区域 | 原子性 | 非法请求 |
| --- | --- | --- | --- | --- |
| `0x01` | Read Coils | DO/硬件表指定位区 | 整次读取一致快照 | 返回异常 |
| `0x02` | Read Discrete Inputs | DI | 整次读取一致快照 | 返回异常 |
| `0x03` | Read Holding Registers | 保持寄存器 | 整次读取一致快照 | 返回异常 |
| `0x05` | Write Single Coil | 可写位 | 单点原子 | 返回异常 |
| `0x06` | Write Single Register | 可写寄存器 | 单点原子 | 返回异常 |
| `0x0F` | Write Multiple Coils | 连续可写位 | 全部成功或全部失败 | 返回异常 |
| `0x10` | Write Multiple Registers | 连续可写寄存器 | 全部成功或全部失败 | 返回异常 |

## 5. 异常响应

| 条件 | Modbus 异常码 | 说明 |
| --- | --- | --- |
| 不支持的功能码 | `0x01 Illegal Function` | TODO：确认 |
| 地址不存在或跨越非法区域 | `0x02 Illegal Data Address` | 不允许部分读取/写入 |
| 值超出允许范围 | `0x03 Illegal Data Value` | 例如非法模式或脉宽 |
| 内部临时失败 | `0x04 Slave Device Failure` | 记录关联日志 |

## 6. 寄存器行为分类

### 6.1 核心动态项

| 分类 | 读行为 | 写行为 | 副作用 |
| --- | --- | --- | --- |
| DO | 返回当前输出 | 按 Level/Pulse 处理 | 影响锁 DI 镜像 |
| DI | 返回当前反馈 | 只读 | 由事实和故障决定 |
| DO 工作模式 | 返回运行时值 | 校验后更新 | 影响后续 DO 写入 |
| DO 脉冲宽度 | 返回运行时值 | 校验后更新 | 影响后续脉冲 |

配置文件只提供工作模式和脉冲宽度的启动/reset 默认值；运行时 Modbus 写值优先。

### 6.2 其他寄存器

- RW：写入后保存并可读回，但首期不模拟额外设备算法。
- RO：返回模板或模块实例定义值。
- 首期不模拟：计数、滤波、主动上传等算法。

## 7. DO 写入规则

### 7.1 Level

- 写 ON：DO 保持 1。
- 写 OFF：DO 变为 0。

### 7.2 Pulse

- 写 ON：DO 变为 1，并启动 `pulseWidthMs`。
- 计时期间再次写 ON：取消旧计时，从本次写入重新计时。
- 到期：DO 自动归零。

## 8. DI 镜像与故障

```text
无故障：
  lockStateDI = lockCommandDO
  lightCurtainDI = actualObstruction

有脱钩故障：
  DI 按故障定义返回，不随事实变化
```

清除故障后，DI 必须按当前 DO/实际遮挡重建，不沿用故障期间旧值。

## 10. reset 行为

- DO、工作模式、脉宽恢复当前有效配置默认值。
- DI 按重置后的 DO 和无遮挡事实重建。
- 其他 RW 寄存器恢复模板/实例默认值。
- 取消全部脉冲和延迟任务。
- 不使用“DO 上电状态”寄存器决定实际 DO 初值。
