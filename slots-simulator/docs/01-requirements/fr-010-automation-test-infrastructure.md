# FR-010 自动化测试基础设施能力

## Description 需求描述

在 [[fr-006-automation-control-api|FR-006]] 自动化控制 API 之上，补充几项面向"无人值守自动化测试"的基础能力，为未来接入 CI 预留架构空间：

- **完整状态重置**：提供接口在不重启进程的情况下，以原子方式清除全部仓位和模块的运行态、故障注入状态及尚未到期的 DO 脉冲计时器；全部仓位光幕 DI 恢复无遮挡并由此推导为"空闲"，DO、DO 工作模式和脉冲宽度恢复当前有效配置声明的默认值；其余可写寄存器恢复为寄存器表模板默认值及模块实例配置覆盖值。重置不读取此前写入的"DO 上电状态"寄存器来决定实际 DO 初值，详见 [[dr-015-do-power-on-state-vs-reset|DR-015]]。
- **健康检查/就绪探针**：提供接口供外部脚本判断 Modbus Slave 和控制 API 是否已启动完成，避免调用方在服务未就绪时连接导致偶发失败。
- **超时测试辅助**：业务超时的计时、阈值和最终判定均由被测主系统负责，模拟器不维护或直接设置"业务已超时"状态。模拟器提供可配置的 DI 反馈延迟、指定 DI 不跟随、门保持开启，以及供自动化脚本跳过模拟器内部非业务等待的能力，使脚本可确定性地构造主系统超时所需的硬件现象。
- **结构化日志**：每次仓位状态迁移产生一条结构化日志（时间戳、仓位号、事件、新状态），输出到 stdout 或文件，供无人值守场景下事后排查。
- **干净的进程生命周期**：能正确响应终止信号并退出，保证端口释放、日志落盘完整，不影响后续实例重新启动。

## Origin 需求来源

服务于 `../00-vision/vision-and-scope.md` 第 2 节第 8 点"CI 接入能力（架构预留）"；理由详见 [[dr-008-ci-readiness|DR-008]]。

## Acceptance Criteria 验收标准

- 调用完整 reset 后，不需要重启进程即可清除全部运行态、模块级和仓位级故障、DI 延迟/不跟随、门保持开启及全部 DO 脉冲计时器。
- reset 后全部光幕 DI 为无遮挡、全部仓位由光幕推导为空闲，DO、DO 工作模式和脉冲宽度恢复当前有效配置默认值；其余在 reset 前已写入的寄存器恢复为模板默认值与模块配置覆盖值。
- reset 是原子操作；调用成功后不会有 reset 前的延迟回调或脉冲计时器再次改变 DI/DO/寄存器。
- 服务未就绪时健康检查接口返回明确的"未就绪"状态，就绪后返回"就绪"。
- 可按目标 DI 配置反馈延迟或不跟随，可使门保持开启，并可跳过模拟器内部等待；这些能力不改变由主系统负责的业务超时阈值和判定。
- 模拟器不提供"直接置为业务超时"接口，也不把业务超时作为自身仓位状态。
- 每次有效状态迁移输出包含时间戳、仓位号、事件和新状态的结构化日志。
- 进程收到终止信号后能正常退出，不留下残留监听端口。
- 当前只要求这些能力存在并可用，不要求真正搭建 CI 流水线本身。

## Related Use Case 关联用例

为 UC-001、UC-002、UC-005、UC-006、UC-010 的自动化测试提供用例隔离、前置构造、异常时序和无人值守运行基础设施。

## Verification 验证方式

- **TC-FR-010-001（待建立）**：Given 多个仓位和模块存在非默认 DI/DO/寄存器值、已注入故障、运行中的延迟及 DO 脉冲计时器；When 调用完整 reset；Then 故障与计时器全部清除、全部仓位为空闲、DI/DO 恢复规定初值、寄存器恢复模板/配置默认值且进程无需重启。
- **TC-FR-010-002（待建立）**：Given reset 前已安排一个尚未触发的 DI 延迟和一个尚未到期的 DO 脉冲；When reset 成功后等待超过两者原定期限；Then 不发生任何来自 reset 前任务的状态回写。
- **TC-FR-010-003（待建立）**：Given 主系统配置了业务超时且模拟器未维护业务超时状态；When 分别设置 DI 延迟、DI 不跟随和门保持开启；Then 模拟器持续呈现对应硬件现象，由主系统自行达到并判定超时。
- **TC-FR-010-004（待建立）**：Given 自动化序列包含模拟器内部等待；When 调用跳过等待能力；Then 模拟器立即推进到等待后的确定性硬件状态，且未直接设置主系统业务超时。
- **TC-FR-010-005（待建立）**：Given 服务正在启动且多个 Modbus 模块尚未全部监听；When 轮询就绪探针直到全部端点可用；Then 未完成时返回明确未就绪，全部完成后返回就绪。
- **TC-FR-010-006（待建立）**：Given Headless Host 已产生状态迁移并占用监听端口；When 发送终止信号；Then 日志包含规定结构化字段并完整落盘，进程退出后原端口可被新实例重新绑定。
