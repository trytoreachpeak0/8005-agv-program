# FR-008 单实例单 AGV

## Description 需求描述

一个模拟器进程实例只模拟一台 AGV 的仓位集合；需要同时模拟多台 AGV 时，通过启动多个独立实例（各自不同端口和配置文件）实现。单个 AGV 实例内部可按 [[fr-014-multi-io-module-simulation|FR-014]] 配置任意数量的 IO 模块与仓位，不设置产品级固定数量上限；实际可配置规模受所选硬件寄存器模板的通道容量、模块监听地址/端口可用性、点位映射完整性和运行机器资源约束。

## Origin 需求来源

部署架构决策，详见 [[dr-007-multi-agv-support|DR-007]]。

## Acceptance Criteria 验收标准

- 同时启动两个配置不同端口的模拟器实例，可分别独立连接和操作，互不干扰。
- 每个进程只暴露其配置所定义的一台 AGV，不在同一进程内复用状态模拟多台 AGV。
- 单实例可配置多个 IO 模块，且模块数与仓位数不受代码中的固定常量限制。
- 超出单模块通道容量时可通过增加模块继续映射仓位；只有模板容量、地址/端口冲突、映射错误或资源不足可使配置失败，并返回明确原因。
- 多实例默认控制 API 均只绑定各自配置的 localhost 端口；Modbus 模块监听端点按各实例配置隔离。

## Related Use Case 关联用例

为 UC-001、UC-002、UC-005、UC-006、UC-010 提供单台或多台 AGV 的隔离测试部署方式，本 FR 不实现这些 UC 的业务流程。

## Verification 验证方式

- **TC-FR-008-001（待建立）**：Given 两份使用不同 API/Modbus 端口且仓位配置不同的文件；When 同时启动两个实例并分别操作相同仓位编号；Then 两实例独立响应且状态互不影响。
- **TC-FR-008-002（待建立）**：Given 硬件模板、可用端口和机器资源满足要求；When 配置多个模块及超过单模块容量的仓位并启动实例；Then 所有模块和仓位均可用，系统不因固定数量上限拒绝。
- **TC-FR-008-003（待建立）**：Given 两个模块配置了相同监听端口或仓位映射超出模板通道；When 校验或加载配置；Then 启动被拒绝并明确指出端口或模板约束，不产生部分运行实例。
- **TC-FR-008-004（待建立）**：Given 实例使用默认控制 API 监听配置；When 从本机与非本机分别访问；Then 仅本机可访问，同时该实例各 Modbus 端点仍按模块配置监听。
