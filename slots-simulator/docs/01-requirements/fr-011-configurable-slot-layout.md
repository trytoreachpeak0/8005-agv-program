# FR-011 可配置仓位版面布局

## Description 需求描述

配置中可声明任意数量的"面"（如 `front`、`rear`，命名不限，不固定写死"前侧/后侧"两个面），每个面各自声明列数（X）与行数（Y）。每个仓位的位置由所属面、起始行、起始列、跨行数与跨列数共同定义；起始行列表示仓位矩形的左上角，`rowSpan`、`columnSpan` 为正整数且默认值均为 `1`。因此既支持普通单格仓位，也支持一个仓位连续占据 `1×N`、`N×1` 或 `N×M` 个基础格。

每个面采用统一尺寸的基础格。跨格仓位必须是连续矩形，不支持 L 形等不规则格子集合、绝对像素定位或仓位级单独旋转。WPF 面板（[[fr-007-wpf-visualization-panel|FR-007]]）将一个仓位渲染为一个状态卡片并填满其合并区域；所有面仍并排同时展示，不提供切换视图。

模拟器的全部配置采用 JSON，并随产品提供机器可读的 JSON Schema 和一份覆盖所有配置字段、可直接启动的完整示例。启动和热重载均须按 Schema 及跨字段业务规则严格校验。WPF 不仅展示配置，还应提供全部配置项的完整编辑与保存能力；任一配置经 WPF 或外部方式保存成功后，模拟器立即热重载，无需重启。热重载校验失败时拒绝整次变更，继续使用上一份有效配置，并向 UI 与日志返回可定位到字段的错误。

背景：现场多仓位 AGV 的仓位通常分为前侧、后侧两组，两侧仓门开启方向相反，操作员要绕到另一侧才能看到另一侧的仓位；每一侧内部的仓位是 X 列 Y 行的网格排列。

## Origin 需求来源

用户新提出的需求：UI 上仓位的展示样式需要可定义，不能是从上到下的列表，要能按"面"（如前侧/后侧）分组，每个面内部按 X 列 Y 行的网格摆放；后续确认实际柜体中一个仓位可能占据多个基础格。设计判断（泛化为任意 N 个面、并排展示、统一基础网格及连续矩形跨格）详见 [[dr-009-slot-layout-model|DR-009]]。

## Acceptance Criteria 验收标准

- 配置文件、模块模板均为 JSON；交付对应 JSON Schema，以及一份覆盖面、仓位、IO 模块、寄存器模板引用、DO 初始模式/脉宽等全部字段的可运行完整示例。
- 启动时若 JSON 语法、Schema 或业务规则校验失败，模拟器拒绝启动并给出字段路径和原因；热重载校验失败时原子拒绝新配置且当前服务保持上一有效状态。
- WPF 可完整编辑并保存所有配置字段；任一配置保存成功后立即热重载并更新界面与运行时，不要求重启。
- 配置文件可声明 N 个面，每个面有唯一标识、名称、正整数列数与行数；实现不设置固定面数或仓位数上限，实际规模仅受运行环境资源约束。
- 每个仓位配置项指定 `faceId`、`row`、`column`、`rowSpan`、`columnSpan`；`row`/`column` 是左上角锚点，两个 span 字段必须为正整数，未填写时均按 `1` 处理以兼容原单格布局。
- 同一面内所有基础格尺寸一致；仓位按 span 合并连续矩形区域，一个仓位始终只显示一个状态卡片并填满该区域。
- 修改面数量、列数、行数、仓位归属、起始坐标或 span 并保存后立即热重载，不需要改代码。
- WPF 面板同时展示全部面的网格（并排布局），不提供切换视图。
- 某个基础格没有被任何仓位覆盖时，该位置留空展示，不报错。
- 严格校验面标识与仓位标识唯一、仓位引用的面存在，以及行列和 span 均为正整数。
- 仓位占用矩形必须完全落在所属面内，即 `row + rowSpan - 1 <= rows` 且 `column + columnSpan - 1 <= columns`。
- 同一面中任意两个仓位的占用矩形不得共享任何基础格；即使起始坐标不同，只要覆盖区域部分相交也视为冲突。越界、重叠、零值或负值均须整体拒绝，不能部分应用。

## Verification 验证方式

- **TC-FR-011-001（编号预留）**
  - **Given** 一份符合 JSON Schema、包含多个面与空白网格位置的完整示例配置
  - **When** 启动模拟器并打开 WPF
  - **Then** 启动成功，所有面并排按配置网格渲染，空白位置保持为空
- **TC-FR-011-002（编号预留）**
  - **Given** 模拟器正使用一份有效配置运行，且在 WPF 中修改任一配置项
  - **When** 保存一份通过全部校验的新配置
  - **Then** 配置被完整持久化并立即原子热重载，界面和运行时采用新值且进程未重启
- **TC-FR-011-003（编号预留）**
  - **Given** 模拟器正使用一份有效配置运行
  - **When** 保存含覆盖区域重叠、跨格越界或不存在面引用的配置
  - **Then** 热重载被整体拒绝，错误包含字段路径与原因，运行时继续使用上一份有效配置
- **TC-FR-011-004（编号预留）**
  - **Given** 启动配置不符合 JSON Schema 或跨字段业务规则
  - **When** 启动模拟器
  - **Then** 模拟器拒绝启动并输出可定位的校验错误
- **TC-FR-011-005（编号预留）**
  - **Given** 同一面包含省略 span 的单格仓位，以及 `1×N`、`N×1`、`N×M` 的矩形跨格仓位，其中一个仓位边界刚好贴合面的最后一行和最后一列
  - **When** 启动模拟器并打开 WPF
  - **Then** 省略 span 的仓位按 `1×1` 渲染，每个跨格仓位只显示一个状态卡片并准确填满配置矩形，所有仓位均位于面内
- **TC-FR-011-006（编号预留）**
  - **Given** 模拟器正在使用有效布局运行
  - **When** 热重载包含 span 为零/负数、跨格越界或两个仓位覆盖区域部分重叠的配置
  - **Then** 整次变更被拒绝，错误定位到冲突字段和仓位，磁盘配置与运行布局均保持上一有效版本
