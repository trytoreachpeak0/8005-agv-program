# FR-014 多 IO 模块实例模拟

## Description 需求描述

一个模拟器进程实例（一台 AGV）可以配置模拟多个物理 IO 模块；所有模块同进程运行，但每个模块各自拥有独立状态和独立 Modbus TCP 服务端点（监听地址/端口），套用某一份 [[fr-013-configurable-register-table-template|FR-013]] 定义的寄存器表模板。仓位的 DO/DI 点位映射采用"模块实例 + 模块内通道序号"两级寻址。

监听主机未配置时默认 `localhost`，避免开发模拟器意外暴露到外部网络；需要远程访问时必须显式配置可监听地址。模拟器不设置固定模块数或仓位数上限，容量由可用系统资源及各硬件模板通道上限共同约束。

背景：一台 AGV 的实际仓位数量会超过单个 IO 模块 16 DO/16 DI 的容量，现场需要用多个物理 IO 模块才能覆盖全部仓位，每个模块各自有自己的 IP（对应说明书里"服务器模式"）。模拟器要按这个真实拓扑去模拟，而不是假装只有一个模块。

## Origin 需求来源

用户澄清：已知实际仓位数量会超过单个 IO 模块的容量，现在就需要支持多个物理 IO 模块拼接模拟，不是以后再扩展。设计判断（现在就支持、与 [[dr-007-multi-agv-support|DR-007]] 的关系）详见 [[dr-012-multi-io-module-support|DR-012]]。

## Acceptance Criteria 验收标准

- JSON 配置可声明 N 个 IO 模块实例，每个实例指定唯一标识、监听地址/端口、套用的寄存器表模板；省略监听地址时使用 `localhost`。
- 所有模块在同一模拟器进程内运行，但端点、寄存器值、DO/DI 动态状态、定时器和故障状态彼此独立；操作或故障一个模块不得影响其他模块。
- 模拟器不设置固定模块数或仓位数上限；每个模块的通道数仍不得超过其硬件模板声明的 DO/DI 上限。
- 每个仓位的 DO/DI 点位配置指定"模块实例 + 模块内通道号"，不再是全局唯一的裸地址。
- 配置严格校验模块标识唯一、模板引用存在、监听地址可解析、端口为合法可用端口、同进程监听端点不重复、通道在模板范围内，并拒绝同一模块同类通道被多个仓位点位重复映射。
- 模块、仓位、端点和映射配置可在 WPF 中完整编辑并保存；保存成功后立即原子热重载，不需要改代码或重启进程。
- 新增/删除模块或修改监听端点时，热重载应完成对应端点的启停与重绑定；若任一新端口被占用或任何配置校验失败，整次热重载被拒绝，全部模块继续使用上一有效配置。
- 被测主系统按真实部署方式分别连接各个模块的地址/端口，模拟器的行为与连接对应数量的真实物理模块一致。
- 每个模块实例除监听地址/端口外，还可以独立配置覆盖其所套用寄存器表模板中的身份类寄存器默认值（如 MAC 地址、IP、设备名等），不强制多个模块实例共享模板里的同一份默认值——真实的多个物理模块各自拥有不同的 MAC/IP/设备名，模拟器如果让所有实例共用模板默认值，会让两个模拟出的模块出现相同的身份信息，与"完整还原真实设备"的目标不符（详见 [[dr-011-full-register-table-fidelity|DR-011]]）。未显式覆盖的模块实例，身份类寄存器仍使用模板中的默认值。

## Related Use Case 关联用例

无直接对应，属于模拟器还原真实多模块硬件拓扑的需求。

## Verification 验证方式

- **TC-FR-014-001（编号预留）**
  - **Given** 同一进程配置多个使用不同端口的模块且未指定监听地址
  - **When** 启动模拟器
  - **Then** 每个模块在 `localhost` 的独立端口监听，且寄存器和动态状态相互隔离
- **TC-FR-014-002（编号预留）**
  - **Given** 配置含重复端点、被占用端口、重复模块标识或重复通道映射
  - **When** 启动或热重载配置
  - **Then** 配置被整体拒绝并指出冲突项，任何模块均不进入部分更新状态
- **TC-FR-014-003（编号预留）**
  - **Given** 多模块服务正在运行且新配置的全部端点可用
  - **When** 在 WPF 修改模块数量或端点并保存
  - **Then** 对应端点立即完成启停或重绑定，其他模块继续可用且进程未重启
- **TC-FR-014-004（编号预留）**
  - **Given** 系统资源足够且每个模块映射均符合自身模板通道范围
  - **When** 配置超过任意先验假定数量的模块和仓位
  - **Then** 模拟器不因固定数量上限拒绝配置，并为每个模块建立独立端点
- **TC-FR-014-005（编号预留）**
  - **Given** 两个模块实例覆盖了不同的身份寄存器值
  - **When** 被测主系统分别读取两个端点
  - **Then** 各端点返回各自覆盖值，未覆盖字段返回共同模板默认值
