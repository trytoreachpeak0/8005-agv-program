# FR-005 Modbus TCP Slave 协议层

## Description 需求描述

模拟器作为 Modbus TCP Slave 运行，按 [[fr-001-configurable-slot-count-and-io-mapping|FR-001]] 的点位映射配置暴露仓位状态寄存器，供被测系统的 IO 对接代码以与连接真实硬件完全相同的方式连接。

一台 AGV 的仓位可能分布在多个物理 IO 模块上，模拟器可同时暴露多个独立的 Modbus TCP 服务端点（对应 [[fr-014-multi-io-module-simulation|FR-014]] 的多模块实例），每个端点各自按其套用的寄存器表模板（[[fr-013-configurable-register-table-template|FR-013]]）暴露寄存器，与被测系统分别连接多个真实物理模块的方式一致。

首期严格支持硬件寄存器表声明的 `0x01`、`0x02`、`0x03`、`0x05`、`0x06`、`0x0F`、`0x10`。每个请求均严格按模板声明的协议地址、连续范围、适用功能码、读写权限和数据范围处理，不提供地址 `+1/-1` 别名或越界兼容。

寄存器行为分为以下两类：

- **动态行为**：DO 当前状态、DI 当前值、DO 工作模式与 DO 脉冲宽度参与模拟器运行。主系统写 DO 会改变输出并按正常或故障注入规则影响锁状态 DI；工作模式与脉冲宽度写入后立即成为后续 DO 动作的运行时依据。启动时两者由配置默认值初始化，状态重置时恢复配置默认值。
- **值保真**：除上述动态项外，模板标记为 RW 的地址保存最近一次成功写入值并可读回；模板标记为 RO 的地址始终返回模板值。首期不模拟 DI 正/负脉冲、计数、电平变化计数、滤波或主动上传算法，这些相关 RW 地址仅保存值，不产生附加行为。

`0x0F` 与 `0x10` 批量写必须原子执行：先校验完整地址范围、权限与每个值，全部合法才一次性提交；任一项非法则整批拒绝，所有目标值保持不变。异常响应遵循 Modbus：不支持的功能码返回 `0x01 Illegal Function`；不存在、越界、跨越不连续区间或不允许该功能码/写入 RO 的地址返回 `0x02 Illegal Data Address`；值或请求长度不合法返回 `0x03 Illegal Data Value`；服务端内部无法完成已验证请求时返回 `0x04 Server Device Failure`。

服务于 `../00-vision/vision-and-scope.md` 第 2 节"对被测系统协议层透明"的目标；协议选型依据 [[dr-005-modbus-protocol-fidelity|DR-005]]。

## Acceptance Criteria 验收标准

- 被测系统的 IO 模块对接代码无需任何修改，仅切换连接地址/端口即可从连接真实 IO 模块切换为连接本模拟器。
- 支持 `0x01` 读线圈、`0x02` 读离散输入、`0x03` 读保持寄存器、`0x05` 写单线圈、`0x06` 写单保持寄存器、`0x0F` 写多线圈、`0x10` 写多保持寄存器。
- 严格执行模板地址、适用功能码、权限与数据范围；非法请求返回明确 Modbus 异常响应且不改变状态。
- DO、DI、DO 工作模式、DO 脉冲宽度具有动态行为；其他 RW 地址保存并返回写入值，RO 地址返回模板值。
- 不实现计数、滤波和主动上传算法；写入其 RW 配置或数值寄存器时仅保存值。
- `0x0F`、`0x10` 批量写具有原子性，不允许部分成功。

## Verification 验证方式

- **TC-FR-005-001（预留）**：Given 模块按硬件表模板启动；When 客户端分别发送 `0x01/02/03/05/06/0F/10` 合法请求；Then 每种请求均返回规范响应，读写值与模板及当前运行状态一致。
- **TC-FR-005-002（预留）**：Given 已知当前寄存器值；When 分别发送不支持功能码、非法地址、写 RO 地址和越界数据；Then 依次返回 `0x01`、`0x02`、`0x02`、`0x03` 异常码，原值均不变。
- **TC-FR-005-003（预留）**：Given DO 工作模式和脉冲宽度已有配置默认值；When 通过 Modbus 改写两者后触发 DO，再调用状态重置；Then DO 按运行时写入值动作，重置后工作模式和脉冲宽度恢复配置默认值。
- **TC-FR-005-004（预留）**：Given 一个 RW 值保真寄存器与一个 RO 模板寄存器；When 写入 RW 地址并读取两者；Then RW 返回最近成功写入值，RO 返回模板值，且不触发计数、滤波或主动上传行为。
- **TC-FR-005-005（预留）**：Given 批量写范围中至少一个地址或值非法；When 发送 `0x0F` 或 `0x10`；Then 返回对应异常响应，批次内所有目标地址均保持写入前值。
