# 每台 AGV 使用独立连接凭证

服务端不能只凭消息中的 `agvId` 或来源 IP 信任车载连接；每台 AGV 必须配置独立 VehicleCredential，并在建立 VehicleConnectionSession、分配会话代次之前完成验证。凭证与 `agvId` 不匹配、缺失或失效的连接不得发送能力快照、业务消息或取得任何控制指令。IP 白名单可以作为附加网络限制，但不能替代车辆身份凭证。

**Status**: accepted

**Considered Options**:
- 只信任 `agvId`（拒绝：任意程序都可声称自己是目标车辆）
- 只按来源 IP 白名单识别车辆（拒绝：地址可变、可复用，也不能证明具体进程身份）
- 每车独立凭证并绑定 `agvId`（采纳）

**Consequences**:
- 三台 AGV 不得共享同一连接密钥或客户端身份。
- 凭证不得进入仓库、普通日志或协议错误响应，部署时单独配置。
- 具体采用证书或共享密钥、传输加密与轮换流程须在通信协议定稿时确定。
