# 车载能力连接时全量同步，变化时可靠推送

车载上位机每次与服务端建立连接时发送完整 OnboardCapabilitySnapshot；配置维护态下成功激活配置后，重新连接时发送 IO 配置版本/指纹和完整能力快照，不发送逐仓拟议配置差异。正常运行期间任一仓位 SlotOperability 变化时，发送可靠、可去重且需要服务端 ACK 的能力变化消息。周期心跳的能力部分只携带当前 capabilityVersion，不重复完整仓位列表；Heartbeat payload 同时按 ADR-cross-0034 携带 safetyStateVersion。服务端发现能力版本未知或不一致时主动查询全量快照。在全量快照缺失、变化未对账或观测已过期时，服务端不得提交新的仓位操作。

**Status**: accepted

**Considered Options**:
- 每次心跳都发送完整仓位能力（拒绝：重复数据且不能清晰表达版本变化）
- 能力变化采用无需 ACK 的普通遥测（拒绝：丢失后服务端可能基于过期能力发出不可撤回指令）
- 连接时全量、变化时可靠推送、心跳携带版本（采纳）

**Consequences**:
- 能力消息与 `OperationProgress` 的可靠性等级不同，必须持久化或保留重发状态直到 ACK。
- 服务端按 AGV 保存最后确认的能力版本，但不保存原始 IO 配置。
- 连接恢复后须先完成能力对账，才能恢复新的业务操作。
- 配置换版后的能力对账完成也不自动退出车辆配置维护态；只有服务端记录明确重新投运后，车辆才能恢复业务就绪。
