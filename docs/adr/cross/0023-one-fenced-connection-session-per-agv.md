# 每台 AGV 只承认一个带代次保护的车载连接会话

车载上位机主动建立并维护到服务端的长连接，服务端监听并管理所有车辆连接。每个 `agvId` 同一时刻只允许一个有效 VehicleConnectionSession；建连握手携带车辆编号、车载程序实例或启动编号和协议版本，服务端为成功会话分配递增代次。新代次生效后拒绝旧会话的所有消息，避免重复车载进程或延迟旧连接形成双主。业务指令、能力快照和结果绑定当前会话代次，但断线重连不得改变原 SlotOperationAttemptId。

**Status**: accepted

**Considered Options**:
- 只按底层 TCP 连接区分，不做车辆级唯一会话（拒绝：无法阻止同一 AGV 的重复进程同时通信）
- 新连接建立后仍接受旧连接未完成消息（拒绝：跨连接乱序会污染能力和操作状态）
- 每车唯一会话，以递增代次隔离旧连接（采纳）

**Consequences**:
- 即使一车一连接，每条消息仍保留 `agvId`，并增加或绑定服务端认可的会话代次。
- 服务端切换到新会话前须保存会话状态；旧会话迟到的 ACK、进度和结果不能直接入账。
- 重连后的操作恢复仍按原 SlotOperationAttemptId 和 ProvenRecoveryCheckpoint 对账，不把新连接当成新操作。
