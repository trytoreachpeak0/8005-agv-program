# 离站安全许可失效采用暂停、取消、急停三级介入

服务端收到 DepartureSafetyRevoked 后，若当前 RIOT 移动任务确认由本系统下发，先执行 OrderHold 并核验车辆确已停止；仓位机构恢复安全后仍不得自动恢复，须重新完成 PreDepartureSafetyCheck，并由服务端明确决定后才执行 OrderContinue。若当前移动任务不是本系统下发或来源无法确定，则执行取消且本系统不负责恢复。OrderHold 或取消失败、或者车辆未在规定时间内停止时，升级为 EmergencyStop 并触发紧急告警。

**Status**: accepted

**Considered Options**:
- 所有情况直接取消（拒绝：本系统任务可安全暂停恢复，取消会丢失执行上下文）
- 所有情况只暂停后自动恢复（拒绝：未知任务不应由本系统代为恢复，且恢复前必须重新核验）
- 本系统任务暂停、未知任务取消、失败升级急停（采纳）

**Consequences**:
- 不能仅凭 RIOT 命令接口返回成功认定车辆已停止，必须观察车辆移动状态。
- OrderContinue 只能由服务端在新的安全核验通过后明确触发，仓门重新锁闭本身不自动恢复车辆。
- EmergencyStop 是暂停/取消无效或未及时停车时的升级手段，不作为每次安全许可失效的首选动作。
