# 站点仓位操作期间服务端必须持续阻断车辆移动

服务端允许提交 Sublot 或下发仓位操作指令前，须先从 RIOT 确认车辆已经停止，并为该 AGV 持久化 StationOperationGuard。该保护覆盖等待输入、等待服务端解析、批量装货、批量卸货、异常暂停和补偿恢复，期间服务端不得向该车产生任何新的移动指令；只有车载上位机报告操作已终结或补偿完成，且最新物理状态确认全部仓门由锁传感器确认锁闭、全部开锁输出回读确认为复位后才可解除。服务端重启、上下层断线或保护状态不明确时不得推断保护已解除。

**Status**: accepted

**Considered Options**:
- 只在下发仓位操作前查询一次车辆是否静止（拒绝：随后仍可能被并发调度重新发车）
- 由车载上位机直接锁定 RIOT 调度（拒绝：车载端不拥有 RIOT 和调度上下文）
- 服务端持久化覆盖整个站点操作周期的移动保护（采纳）

**Consequences**:
- 所有服务端移动入口，包括自动调度、人工派车、充电和恢复命令，都必须经过同一 StationOperationGuard。
- 允许输入 Sublot 本身已经进入站点操作周期，不能等到仓位清单生成后才建立保护。
- 解除保护后仍须执行 PreDepartureSafetyCheck；“保护已解除”不等于可以直接发车。
