# 现场证据

本层保存每一轮实验的原始脱敏事实。

## 不可变规则

- 每轮使用独立目录，历史轮次不得覆盖。
- `runs/` 中保存完整脱敏请求和响应；摘要不能替代完整响应。
- 任何人工动作都要带时间戳进入执行日志。
- 未执行的实验保持未执行，不补写推测结果。
- 证据发现与已有知识冲突时，保留原证据并登记冲突，不修改历史来“统一口径”。

## 轮次元数据

新轮次计划必须包含：

- 环境和平台版本。
- Swagger、TSL、地图和车型信息。
- 实验范围、写操作批准范围和明确跳过项。
- 测试车稳定别名及脱敏策略。
- 开始前状态、结束后善后状态。

第一轮位于 [`rounds/2026-07-15-round-1/`](./rounds/2026-07-15-round-1/)。

新轮次从 [`round-template/`](./round-template/) 复制计划和执行日志结构。
